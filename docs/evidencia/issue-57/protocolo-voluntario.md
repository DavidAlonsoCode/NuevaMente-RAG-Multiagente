## Versión y entorno

- Fecha y persona voluntaria (nombre público o identificador confirmado): pendiente.
- Confirmación de que es ajena al equipo: pendiente.
- Commit revisado (`git rev-parse HEAD`), rama y URL/hash del README usado: pendiente.
- Sistema, arquitectura y terminal; versiones Git, Python, Node/npm o Docker/Compose: pendiente.
- Directorio nuevo y ausencia de configuración/venv/datos heredados: pendiente.
- Recorrido elegido: simulado funcional / nativo real / Docker con mocks: pendiente.
- Configuración no secreta, puertos y proveedores: pendiente. No adjuntar `.env`,
  claves, tokens, códigos de recuperación ni URLs firmadas.

Si el README revisado aún no está publicado en `develop`, el equipo debe aportar
la versión documental exacta. Registrar su hash junto al commit de código;
no probar otro README y atribuirle el resultado a este.
El recorrido real exige autorización separada del operador para consumir proveedores;
la plantilla no la concede. Docker con mocks comprueba arranque y conectividad,
sin acreditar carga/generación funcional ni sustituir el recorrido simulado.
